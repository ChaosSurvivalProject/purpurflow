## 5.2 关键接口契约与签名说明

签名与提示词 §3 一致（可调整但已说明理由）：

```java
// FrameCodec —— 帧层编解码，com.purpurflow.common.protocol
public final class FrameCodec {
    public byte[] encode(List<Message> msgs) throws FrameException;
    public List<Message> decode(byte[] frame) throws FrameException;
}

// EgressGate —— 出站背压闸门，false = 背压丢弃（H3）
public interface EgressGate {
    boolean offer(Player player, Frame frame, Priority priority);
}

// ResumeService —— 重连补偿（H4）
public interface ResumeService {
    ResumePlan resume(UUID sessionId, long epoch, long ackSeq);
}

// CapabilityNegotiator —— 能力协商（H5）
public interface CapabilityNegotiator {
    ProtocolVersion negotiate(Capability client, Capability server); // DISABLED if mismatch
}
```

> 签名理由：`encode(List<Message>)` 对应「一帧多消息合包」；`ackSeq` 用 `long` 而非 varint 语义类型以便快照比对；`ProtocolVersion` 用枚举便于白名单表达 `DISABLED`。

## 5.3 核心路径伪代码

### 出站（server → client）

```text
onStateChange(player, delta):
  session = sessions.get(player)
  if session.mode == VANILLA: return              // H2
  frame = FrameCodec.encode([delta.asMessage(), ...])  // L2/L3/L1 合包
  priority = delta.isControl ? CONTROL : (delta.isTelemetry ? TELEMETRY : STATE)
  if !egress.offer(player, frame, priority):       // H3 背压
      session.dirtyBitmap.merge(delta)             // 合并脏位图，不排队
  else:
      channel.send(player, "purpurflow:main", frame.bytes)
```

### 入站（client → server）

```text
onPluginMessage(channel="purpurflow:main", player, bytes):
  if !whitelist.accepts(player): return
  try:
     messages = FrameCodec.decode(bytes)           // 白名单 schema
  catch FrameException:
     securityCounter.invalidFrame++; return        // 2.9
  for msg in messages:
     switch msg.type:
        HELLO     -> handshake.onHello(player, msg)
        RESUME    -> resume.onResume(player, msg)
        ACK       -> session.ack(msg.seq)
        default   -> dispatcher.dispatch(player, msg)
```

### 客户端发送与重组

```text
sendToServer(payload):
  if !ClientPlayNetworking.canSend(TYPE): return   // L6 能力探测
  bytes = FrameCodec.encode([payload])
  if bytes.length > UPSTREAM_LIMIT (32KiB, 探测值):
      bytes = fragmenter.split(bytes, negotiatedChunk)
  ClientPlayNetworking.send(new FlowPayload(bytes))

onFlowPayload(payload):
  full = reassembler.accept(payload.bytes)         // 分片重组，带超时/上限
  if full == null: return                          // 未收齐
  for msg in FrameCodec.decode(full):
     mirror.apply(msg)                             // 幂等 last-write-wins
     ackReporter.note(maxSeq)
```

### 握手（H5）

```text
onHello(clientHello):
  v = negotiator.negotiate(clientHello.capability, serverCapability)
  if v == DISABLED:
      session.mode = VANILLA; send(DISABLED); return   // 不踢人
  sessionId = newSession(); dictVer = pickDict(v)
  send(HELLO_ACK{ver=v, sessionId, dictVer, serverMaxChunk, enhanced=true})
  if clientHello.dictVer != dictVer:
      send(DICT_SYNC{dict.diff(clientHello.dictVer, dictVer)})
  session.mode = ENHANCED
```

## 5.4 配置样例（全部开关默认值）

见 `server/src/main/resources/purpurflow.yml`，关键默认值：

| 配置项 | 默认值 | 含义 |
|---|---|---|
| `enabled` | `true` | 增强流总开关（一键回滚） |
| `protocol-whitelist` | `[1]` | 协议版本白名单 |
| `dictionary-version` | `1` | 字典版本 |
| `compression.enabled` | `false` | L4 帧级压缩（默认关） |
| `compression.threshold-bytes` | `1024` | 超过才考虑压缩 |
| `backpressure.high-watermark` | `1024` | 队列高水位 |
| `backpressure.max-queue-per-player` | `2048` | 单玩家队列上限 |
| `rate.limit-bytes-per-sec` | `262144` | 每玩家每秒字节配额 |
| `rate.limit-packets-per-sec` | `500` | 每玩家每秒包配额 |
| `resume.seq-log-length` | `512` | seq 日志长度 |
| `resume.snapshot-ttl-sec` | `300` | 快照保留时间 |
| `handshake.timeout-ms` | `3000` | 握手超时 |
| `fragment.chunk-bytes` | `0`(探测) | 分片大小，0=运行时探测 |
| `security.max-frame-bytes` | `1048576` | 单帧上限（下行） |
| `security.dedup-window` | `256` | 去重窗口 |
| `optional.packetevents.enabled` | `false` | 可选 ② 拦截层（默认关） |
