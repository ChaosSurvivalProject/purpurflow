# 06 · 测试、压测与验收（第 4 阶段）

## 6.1 单元测试（test 模块，JUnit 5）

| 测试类 | 覆盖点 |
|---|---|
| `VarIntsTest` | VarInt/VarLong 边界（0, 1, 127, 128, 2^31-1, 负数）、ZigZag 往返 |
| `FrameCodecTest` | 编解码往返、多消息合包、magic/ver 校验、超长拒绝 |
| `FragmentTest` | 分片重组乱序 / 丢失 / 超时 / 重复 seq |
| `DeltaTest` | delta + 脏位图正确应用、last-write-wins |
| `DedupWindowTest` | 去重窗口滑动、窗口外 seq 不误杀 |
| `DictSyncTest` | 字典版本回滚、增量同步幂等 |
| `BitPackerTest` | 布尔/小枚举打包往返 |
| `BlockPosTest` | BlockPos 打包往返与有效范围 |

**黄金向量**：`test/resources/golden/` 下存放固定 bytes → 结构的编解码黄金向量，防止协议漂移。

## 6.2 集成测试

| 场景 | 断言 |
|---|---|
| 握手全流程 | HELLO→HELLO_ACK→DICT_SYNC→STEADY 状态迁移正确 |
| 版本不匹配降级 | 降版本重试一次，仍失败→DISABLED，不踢人 |
| **vanilla 客户端进服回归** | 未装 Mod 客户端正常进服、无增强帧、无 kick、无卡顿（硬门槛） |
| 重连增量补发 | RESUME 命中→DELTA(fromSeq)，不丢不重 |
| 全量快照兜底 | seq 日志裁剪后→FULL_SNAPSHOT |
| 切服 | 新 session 重新握手，状态正确迁移 |
| 弱网模拟 | 延迟/抖动/丢包下不雪崩（H3） |
| 队列积压与熔断 | 高水位触发丢弃/合并，不 OOM |
| 恶意超限 payload | 超限拒绝 + 安全计数，不崩服 |

## 6.3 压测口径（每一项都要给前后对比数字）

| 指标 | 口径 | 目标 |
|---|---|---|
| 总字节数 | 单位时间链路总字节（开/关增强流） | 显著下降 |
| 包数 | 同一逻辑更新的包数 | 大幅下降（合包） |
| 有效载荷比 | 有效逻辑信息字节 / 链路总字节 | 上升 |
| 每逻辑更新平均字节 | 总字节 / 逻辑更新数 | 下降 |
| P50 / P99 延迟 | 端到端 RTT 与逻辑更新延迟 | P99 不劣化 |
| 丢包率 | 接收端缺失 seq 比例 | 下降 |
| 重连恢复时间 | 断线→状态一致耗时 | 不劣化 |
| 服务端 CPU/内存增量 | 开/关增强流的资源差 | 可控 |
| 单玩家与满员场景 | 1 人 vs 满员 | 均达标 |
| 开启/关闭压缩 A/B | 同一负载，压缩 on/off | 净收益为正才开 |

统一压测脚本：`test/bench/` 下提供发包器与统计器，输出 CSV（字段对应上表），前后对比由脚本自动生成对照表。

## 6.4 验收门槛示例

- 总字节与包数显著下降（建议 ≥30%）。
- 有效载荷比上升、每逻辑更新平均字节下降。
- P99 不劣化（不允许以牺牲实时性换带宽）。
- 5% 丢包弱网下不雪崩（无 OOM、无 kick、无级联重发）。
- 重连不丢不重。
- vanilla 客户端零回归。
- 一键关闭增强流后行为与原版一致（`enabled=false` 即等效无 Mod）。
